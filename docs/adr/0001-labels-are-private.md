# Labels are private; visitors only see finished headlines

Labels are tags on players that headlines are written from, and some are unflattering. They are kept in a private book that only the editor can read, and never sent to visitors. The editor's app writes the headlines and saves the finished sentences, and visitors read those. The alternative was to ship labels to every visitor and write headlines in their browsers, which is simpler but would expose every label.

Consequence: headlines on a visitor's screen are only as fresh as the editor's last save, so new headlines appear after the editor opens the site.
