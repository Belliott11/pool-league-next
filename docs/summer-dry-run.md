# Summer dry run

A ten-minute test of game day before the first real game, so nothing surprises anyone. Two people with phones:

- **Ben** on the editor's scoring screen (signed in), who starts and throws away the test game.
- **Adam**, or anyone, on a phone that is not signed in, as a friend watching.

The test game is thrown away at the end, so it never reaches the game list or the stats. Only the editor's screen can throw a game
away, so **only Ben finishes or discards it**. A friend's "Finish game" saves the game for real.

## Before you start

1. Both phones open https://intel.poolean.net.
2. For the stream part: the upstairs phone can go live on YouTube (unlisted). A new YouTube account has to request live streaming
   once, which can take up to 24 hours, so do that a day ahead.

## 1. Start a test game (Ben)

1. Games, then **Start a live game**.
2. Put two players on Team A and two on Team B. Set **Play to** low, such as 5.
3. Tap **Start game**.

Check: Adam's phone shows the live game on its own within a few seconds (the Games page, "Tap to watch. It updates by itself.").

## 2. Score from both phones

1. Ben: tap a player, then 2. Then another player, then 1.
2. Adam: tap the live game, then **Keep score**, and add a basket for someone on the other team.
3. Ben: **Undo last** once.

Check: both phones show the same score within a moment, and the undo took back Ben's last basket only.

## 3. Flag a review

1. Adam: tap **Review that**, type a note such as "test, foul on Ben", then Save.
2. Ben: tap **Review that** and save without a note.

Check: the button now says "(2 flagged)" on Ben's screen.

## 4. The stream (if the upstairs phone is live)

1. On the upstairs phone, in YouTube, Share, Copy link.
2. On either phone, under the score: "Streaming this game? Paste the YouTube live link", paste it, save.
3. Both phones: the stream shows under the score. Try **10s**, **30s** and **Live**.
4. While watching the stream, tap **Review that** once more.

Check: the stream plays on both phones, the replay buttons jump back, and Live returns to now. A review flagged while watching the
stream is placed exactly in the video later, with no clock involved.

If Adam's app is ready, also press **Save that** in it once, and check a moment appears in the review list.

## 5. Throw it away (Ben)

1. Ben: **Discard game**, then **Discard**.

Check: the game disappears from both phones and is not in the game list.

## If something goes wrong

- Write down the step number and what you saw, or take a screenshot, and send it to Claude.
- A friend's phone that loses signal keeps its taps and sends them when it reconnects; a basket is never counted twice.
- If a test game was finished by mistake, Ben can delete it from the game's page, or ask Claude to (a snapshot is taken first).
